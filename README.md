# MindBuzz: Multi-Modal Educational AI Platform for Character Tracing & Phoneme Pronunciation Assessment

> **An end-to-end interactive AI studio for children**, combining **Computer Vision (EMNIST CNN)** for handwriting tracing, **Phoneme-Level Acoustic Assessment (Whisper ASR + MFA + GOP)** for speech evaluation, and **LPU-Accelerated LLMs (Groq Llama-3.3 70B)** for personalized AI tutoring.

---

## Executive Summary & Presentation Overview

MindBuzz is designed to solve a core challenge in early childhood education: **giving children instant, accurate, and encouraging feedback on both writing and speaking.** 

Unlike simple letter-tracing apps or generic voice recognizers, MindBuzz uses a **5-Model AI Pipeline** that evaluates:
1. **Visual Accuracy**: Digit and letter stroke structure via a 47-class Deep Convolutional Neural Network (EMNIST CNN).
2. **Acoustic Phonetics**: Per-phoneme speech quality using Montreal Forced Alignment (MFA) and Goodness of Pronunciation (GOP) scoring.
3. **Adaptive AI Coaching**: Real-time advice generated by Groq Llama-3.3 70B LLM.

---

## Child Security, Privacy & Safety Architecture

Child safety and data privacy are core architectural priorities in MindBuzz:

1. **10-Second Auto-Stop Recording Ceiling**:
   * **Security Rule**: The voice recording interface strictly caps every microphone recording session at **exactly 10 seconds** (`micSecondsRemaining = 10` countdown timer in `canvas_engine.js`).
   * **Purpose**: Prevents accidental long recordings, prevents unauthorized background audio capture (eavesdropping protection), and protects browser/server memory.

2. **Ephemeral In-Memory Audio Processing**:
   * All voice recordings are converted to temporary 16kHz PCM WAV buffers in RAM.
   * Audio files are processed in transient memory (`temp_rec_*.wav`) and **immediately deleted** after evaluation.
   * **Zero Voice Retention**: No child voice recordings are ever stored, logged, or saved to persistent databases.

3. **Child-Safe Guardrails & System Prompts**:
   * Groq LLM prompts are strictly constrained with system-level instruction limits:
     > *"You are a warm, encouraging AI speech tutor for children... Keep your response under 20 words."*
   * Ensures all AI interactions provide positive reinforcement, age-appropriate guidance, and zero complex jargon.

4. **Zero Personally Identifiable Information (PII)**:
   * Requires no account creation, student names, emails, or personal tracking.
   * Progress scores and unlocked characters are kept strictly inside the user's local browser storage (`localStorage`).

## Deep Dive into All 5 AI Models & Datasets Used

### 1. OpenAI Whisper Speech Recognition Engine (ASR)
* **What it Does**: Converts spoken audio from children into text to perform free-form speech transcription and determine if the uttered word matches the target word.
* **Architecture**: Encoder-Decoder Transformer model with log-mel spectrogram audio input processing.
* **Dataset Used**: Trained on **680,000 hours of supervised multilingual and English speech data** collected from diverse speakers, accents, and noisy acoustic environments.
* **Key Feature**: Processes 16kHz PCM audio buffers directly in Python memory without requiring external binary dependencies (`ffmpeg` or `sox`).

---

### 2. Montreal Forced Aligner (MFA) & Acoustic Boundary Segmenter
* **What it Does**: Performs forced alignment by mapping audio frames to the exact expected target word's phoneme sequence, generating precise `[start, end]` timestamps for every phoneme.
* **Architecture**: Deep HMM/GMM-based forced aligner integrated with acoustic spectral boundary segmentation algorithms.
* **Datasets Used**:
  * **LibriSpeech 960-Hour Audio Corpus**: Used for acoustic model training and phoneme transition probabilities.
  * **Carnegie Mellon University (CMU) Pronouncing Dictionary**: Used for resolving English words into standard ARPAbet phonetic representations (`"BANANA"` $\rightarrow$ `['B', 'AH', 'N', 'AE', 'N', 'AH']`).

---

### 3. Goodness of Pronunciation (GOP) Acoustic Scoring Engine
* **What it Does**: Calculates a per-phoneme pronunciation quality score (0–100) and overall word confidence score by measuring how closely the child's acoustic waveform matches expected target phoneme acoustics.
* **Architecture**: Custom signal-processing log-likelihood ratio estimator and spectral energy analyzer.
* **Dataset / Reference Priors**:
  * **CMUDict Phonetic Category Mapping**: Categorizes phonemes into Fricatives (`S`, `F`, `SH`, `Z`), Vowels (`AE`, `AH`, `IY`), and Nasals/Plosives (`B`, `D`, `G`, `K`, `P`, `T`).
  * Evaluates sub-frame **RMS Energy Variation** and **Zero-Crossing Rate (ZCR)** turbulence to judge acoustic stability.

---

### 4. EMNIST Convolutional Neural Network (CNN) Handwriting Classifier
* **What it Does**: Classifies child drawing strokes on the HTML5 canvas to check if the drawn character matches the target letter (**A–Z**, **a–z**) or digit (**0–9**).
* **Architecture**: Deep 2D Convolutional Neural Network (`best_tracing_model.keras`) featuring alternating Conv2D, BatchNorm, MaxPooling2D, and Dense Softmax layers.
* **Dataset Used**: Trained on the **EMNIST (Extended MNIST) Balanced Dataset**, consisting of **112,800 handwritten character and digit images** across 47 balanced classes ($28 \times 28$ pixel grayscale tensors).
* **Preprocessing**: Extracts stroke bounding boxes to preserve aspect ratio, scaling strokes into a centered $20 \times 20$ grid inside a $28 \times 28$ normalized image tensor (`[0.0, 1.0]`).

---

### 5. Groq Llama-3.3 70B Versatile LLM (Speech & Handwriting Tutor)
* **What it Does**: Generates personalized, child-friendly AI tutor advice. Provides step-by-step handwriting stroke tips when drawing fails and pinpointed phonetic coaching when speech pronunciation falls below threshold.
* **Architecture**: Meta Llama-3.3 70B running on Groq's specialized Language Processing Unit (LPU) hardware for ultra-low latency ($<300\text{ms}$).
* **Dataset Used**: Pre-trained on Meta's **15+ Trillion token multilingual dataset** and fine-tuned with Reinforcement Learning from Human Feedback (RLHF) for child-safe educational instruction.

## How Pronunciation Assessment Was Improved

1. **Child-Calibrated Confidence Threshold (50%)**:
   * **Problem**: Standard ASR models expect adult articulation ($\ge 65\%$ threshold), causing false failures for young children with developing speech patterns.
   * **Solution**: Lowered the GOP letter pass threshold to **50.0%**, providing a realistic, encouraging evaluation benchmark tailored for children.

2. **Phoneme-Level Diagnostics**:
   * Instead of giving a generic "wrong word" error, the system pinpoints the exact mispronounced letter (e.g. *Letter 'T' at 38% confidence*) so the child knows exactly what sound to practice.

3. **78-Word Phonetically Distinct Vocabulary**:
   * **Problem**: Short 1-syllable words like `"ant"` cut off abruptly and sound identical to `"and"` when final stop consonants are unreleased.
   * **Solution**: Curated 3 distinct, multisyllabic, child-friendly words per letter A–Z (e.g., `Apple`, `Anchor`, `Animal`; `Banana`, `Basket`, `Button`) that Whisper ASR transcribes with high reliability.

4. **Expanded CMUDict ARPAbet Coverage**:
   * Added complete ARPAbet phoneme definitions for all 78 vocabulary words in `backend/speech/alignment/dictionary.py` to ensure 100% MFA alignment accuracy.

## Hard Engineering Challenges Overcome

### Challenge 1: Whisper ASR vs. MFA/GOP Phonetic Discrepancy
* **Issue**: When a child says `"ANT"`, Whisper often transcribes `"And..."` because unreleased stop consonants cut off softly. Users wondered why Whisper heard `"And..."` while MFA/GOP analyzed `"ANT"`.
* **Solution**: Documented and demonstrated that Whisper is a **free-form language ASR**, while MFA/GOP is **forced acoustic alignment**. MFA forces the audio onto `AE` $\rightarrow$ `N` $\rightarrow$ `T` and correctly detects that the `'T'` sound was weak (38%), explaining *why* Whisper misheard it!

### Challenge 2: Duplicate UI Feedback Clutter
* **Issue**: The UI previously rendered two separate stacked card blocks for speech status and Groq tutor output, repeating identical text.
* **Solution**: Merged all status lines, attempt badges, Groq tutor advice, and problem letter rows into **1 Unified Single Card Component** in `frontend/index.html` and `canvas_engine.js`.

### Challenge 3: Suppressing TensorFlow C++ & ABSL Terminal Noise
* **Issue**: Launching Python backend scripts printed ugly C++ log warnings (`TF_ENABLE_ONEDNN_OPTS`, `absl::InitializeLog()`).
* **Solution**: Programmatically injected environment flags (`TF_ENABLE_ONEDNN_OPTS=0`, `TF_CPP_MIN_LOG_LEVEL=3`, `ABSL_LOG_LEVEL=3`, `GLOG_minloglevel=3`) into `run.py` and `backend/main.py` before TensorFlow imports, ensuring clean terminal output.

### Challenge 4: API Token Optimization Strategy
* **Issue**: Calling Groq LLM API on every single correct pronunciation consumed unnecessary tokens and rate limits.
* **Solution**: Designed an intelligent dual-path pipeline:
  * **Pass ($\ge 50\%$)**: Skips Groq API calls (saving 100% of tokens) and returns instant coded praise.
  * **Fail ($< 50\%$)**: Calls Groq LLM API exclusively to generate custom feedback pinpointing the mispronounced letter.

## API Architecture & Handling

MindBuzz runs on a high-performance **FastAPI** backend supporting asynchronous request handling, CORS middleware, and multipart binary streaming.

| Endpoint | Method | Input | Description |
|---|---|---|---|
| `/api/evaluate-speech` | `POST` | `audio_data` (WAV), `target` (str) | Evaluates spoken audio, checks unlock state, and returns Groq speech tutor feedback. |
| `/api/pronunciation` | `POST` | `audio` (WAV), `expected_word`, `expected_letter` | Executes full MFA + GOP pipeline and returns detailed `PronunciationReport` JSON. |
| `/api/evaluate` | `POST` | `file` (PNG blob), `target_character` | Runs EMNIST CNN inference on canvas drawings and returns stroke coaching. |
| `/api/health` | `GET` | None | Returns backend operational status and Whisper preloader readiness. |

## How to Run the Project

### One-Click Start Command:
```bash
python run.py
```

`run.py` automatically initializes the HTTP frontend server (Port 3000), starts the FastAPI backend (Port 8000), preloads the Whisper ASR engine, and launches your browser automatically when all systems are ready.
